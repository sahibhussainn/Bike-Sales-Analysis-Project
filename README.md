# Bike Sales Analysis Dashboard (Excel)

## Project Overview

This project focuses on analyzing bike purchasing behavior using Microsoft Excel. It explores customer demographics, income levels, commute distances, education, occupation, and other factors to understand patterns associated with bike purchases.

An interactive Excel dashboard is developed using Pivot Tables and charts to present insights in an easy-to-understand visual format.

## Objectives

- Analyze customer demographics and purchasing behavior.
- Understand the relationship between income and bike purchases.
- Compare purchasing patterns across gender and marital status.
- Explore customer characteristics such as age, education, occupation, and commute distance.
- Present key findings through an Excel dashboard.

## Dataset Description

The workbook contains customer-level information with the following attributes:

| Column | Description |
|---|---|
| ID | Unique customer identifier |
| Marital Status | Customer's marital status |
| Gender | Customer's gender |
| Income | Annual customer income |
| Children | Number of children |
| Education | Education level |
| Occupation | Customer's occupation |
| Home Owner | Home ownership status |
| Cars | Number of cars owned |
| Commute Distance | Distance travelled to work |
| Region | Customer's geographical region |
| Age | Customer's age |
| Purchased Bike | Whether the customer purchased a bike |

## Workbook Structure

The Excel workbook contains four worksheets:

1. **bike_buyers** – Original customer dataset.
2. **Working Sheet** – Prepared dataset with standardized categorical values and age brackets.
3. **Pivot_Table** – Aggregated analysis using Pivot Tables.
4. **Dashboard** – Visual presentation of bike purchasing analysis.

## Key Analysis Areas

- Bike purchase distribution across customer segments.
- Income comparison between bike purchasers and non-purchasers.
- Gender-based purchasing patterns.
- Customer age group analysis.
- Regional and commute-distance comparisons.
- Customer demographics and purchasing behavior.

## How to Use

1. Clone or download this repository.
2. Open the Excel workbook.
3. Navigate to the `Dashboard` worksheet.
4. Explore the visualizations and available dashboard filters.
5. Review the `Pivot_Table` worksheet for supporting analysis.
